# 📄 Blaze MD ↔️ PDF

Blaze Markdown to Pdf is an unambitious markdown to pdf converter (pdf to markdown as well) made with blazor wasm

## ⚡ Getting Started

Use for free (and feel free to report bugs, or contribute as well) [here](https://weslleymurdock.github.io/BlazeMd2Pdf)

## 🔧 Building and Running

First ensure that you have the .NET 10.0 LTS SDK and runtime installed.

Then clone the repository and navigate to project folder:

```bash
git clone https://github.com/weslleymurdock/BlazeMd2Pdf.git
cd ./BlazeMd2Pdf/src/BlazeMd2Pdf
```

After that, at project directory, you can run directly: 

```bash
dotnet run
```
or run watch for modify/test changes:

```bash
dotnet watch
```
